# Задачи

## Сироты celery

- [x] `_BASE_WHERE` — точечная замена условия возраста там, где `<колонка> < :cutoff` мало
      (нужен OR, а `_EXTRA_COND` умеет только AND)
- [x] Граница по `id`: максимум среди уже старых, `NULL` при их отсутствии не удаляет ничего
- [x] Комментарий про трёхзначную логику: у живой строки условие именно `NULL`, и «чинить»
      это через `COALESCE` нельзя
- [x] Проверено на стенде откатом: подделанная из существующей строки старая сирота
      удаляется (было — нет), обе живые `STARTED` остаются

## Реиндекс

- [x] `db_reindex(table, conn_id, timeout)` вместо `(conn_id, schema, timeout)`,
      `REINDEX TABLE CONCURRENTLY main.<table>`
- [x] Таск — цикл по XCom `clean` по образцу `vacuum`: таймаут на таблицу, пропуск в свою
      строку, таблица в заметке
- [x] Список только из XCom, не из переменной: имя таблицы уходит в SQL подстановкой
